# 📋 Журнал ремонтных работ

Android-приложение для ведения журнала ремонтных и технических работ с фотографиями.

## 📲 Скачать приложение

Перейди в раздел [**Releases**](../../releases/latest) и скачай последний APK файл.

> **Как установить:** скачай APK → открой на телефоне → разреши установку из неизвестных источников → готово!

---

## Что умеет приложение

- 📸 **Фото** — снимай результат работы прямо из приложения или выбирай из галереи
- 📝 **Подпись** — пиши коротко что сделал, адрес определится автоматически
- 🗓️ **Дата** — проставляется автоматически, но можно изменить вручную
- 🗂️ **Категории** — встроенные (качели, лавочки, освещение...) и свои собственные
- 🔍 **Поиск** — по адресу, типу работы, дате
- 🤖 **AI-ассистент** — задавай вопросы: «Сколько качелей починили на Тевосяна 22а?»

---

## Как работает AI-ассистент

Ассистент работает на Google Gemini (бесплатно — 1500 запросов в день).

1. Зайди на [aistudio.google.com](https://aistudio.google.com/app/apikey)
2. Создай бесплатный API ключ
3. В приложении: ⚙️ Настройки → вставь ключ → Сохранить

---

## Стек технологий

- **Kotlin** + **Jetpack Compose** — современный Android UI
- **Room** — локальная база данных (работает без интернета)
- **Hilt** — внедрение зависимостей
- **Coil** — загрузка фотографий
- **Google Gemini API** — AI-ассистент

## Разработка

Проект разрабатывается открыто. Если нашёл баг или есть идея — открывай [Issue](../../issues).

### Сборка из исходников

```bash
git clone https://github.com/mlplmkokn-cell/WorkJournal.git
cd WorkJournal/WorkJournal
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`
